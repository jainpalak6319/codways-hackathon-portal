# Codways Hackathon Management Portal

A centralized platform for managing hackathons organized by Codways Technologies.

## Features

### Public Website
- Home Page
- Hackathon Listings
- Hackathon Details
- About Us
- Contact

### Admin Portal
- Dashboard
- Hackathon Management
- Participant Management
- Team Management
- Judge Management
- Submission Management
- Analytics

### Participant Portal
- Dashboard
- Register for Hackathons
- Team Creation
- Team Management
- Project Submission
- Leaderboard

### Judge Portal
- Assigned Projects
- Evaluation System
- Scoring Rubrics
- Feedback Submission
